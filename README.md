# 🎬 Movie Explorer

Приложение для поиска фильмов с возможностью фильтрации, добавления в избранное и просмотра детальной информации.

## 🚀 Функционал

- Поиск фильмов по названию
- Фильтрация по жанрам, году выпуска и рейтингу
- Пагинация (постраничная навигация)
- Добавление/удаление из избранного (Zustand + localStorage)
- Детальная страница фильма (постер, описание, бюджет, сборы, ссылка на сайт)
- Адаптивная стилизация (CSS-модули)

## 🛠️ Технологии

- React 18
- TypeScript
- Vite
- React Router
- Zustand
- CSS Modules
